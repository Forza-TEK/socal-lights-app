# Function audit, 2026-11-24

Scope: what the product does today (code, production data, tests), not look and feel. Read-only: no product code, deploy, email, Stripe call or production write was made. Production D1 was read with SELECT only; `npm test` was run (1221 pass, 0 fail on the real clock); one public GET each of `/api/events`, `/api/posts`, `/api/health` and the home page headers was made.

Already fixed this session and not repeated: event video clips, Admin photo/video upload, claim-to-manage, Promote buttons, paid pin/top spot for homes of any approved status, "possible matches" on add-event, the migration gate for organizer-managed events, duplicate merges, ambiguous-address flagging for events, the Admin phone bottom bar. Known open items (Play Console, new iOS build, paid placement web-only in apps, owner-edit protection covering migrations only) are not re-investigated.

Priorities: P0 fix now, P1 soon, P2 later, P3 nice to have. Effort: S under a day, M a few days, L a week or more.

## Executive summary: the 10 most important gaps, ranked

1. **372 live events are still "expected" (28% of 1,325 current or upcoming), 219 of them start within 14 days, and nothing automatic can confirm them** (F-18). The only auto-confirm job skips every sweep row.
2. **The App Store review note and policy doc say a person reviews every listing before it appears. The code publishes homes and events immediately** (F-41). A wrong statement to App Review about user-generated content is a removal risk.
3. **Content moderation is an 11-word English regex plus Turnstile** (F-02). Homes, photos and events go public with no human look. First-time posters get no extra check.
4. **Photo backup misses event owner photos, all video clips, hidden/organizer home photos, contest logos and sponsor receipts** (F-22). Restoring from the backup would lose them.
5. **Grok-sent events publish as "confirmed" on the sender's say-so**; the server never opens the page it cites (F-20). 258 live events come from this path.
6. **Account deletion leaves the user's events public with their uploaded photos/video, and a paid pin on such an event is not flagged for refund** (F-09).
7. **Any signed-in user can overwrite an unmanaged listing through "this is my event"** (name, dates, address, link), live at once, marked confirmed, with only a 330-character note to undo it (F-03).
8. **CI has no job timeouts on the required Tests job and 6 more workflows** (F-47), and **tests break when the calendar moves** (F-48): with the clock set to 2027-03-15, 19 tests failed.
9. **Homes have no duplicate-address check outside contests** (production already has two approved homes at 25972 Limerick Ln) and **home pins ignore ambiguous-address detection** (F-01, F-04).
10. **CSP is Report-Only with no collector, and the safe, non-inline directives are not enforced yet** (F-38). Missing client error reporting (F-36) means front-end breakage is invisible.
